# 桌面 Agent UI 质量验收清单

本清单定义了桌面 Agent UI 交付与合并前的硬性质量门禁，重点通过自动化脚本与真实环境核验，杜绝阴影裁切、输入法异常与滚动跳帧等高频缺陷。

---

## 1. 自动化阴影裁切审计（clip-audit）

只要界面改动涉及 `box-shadow`、`drop-shadow`、无边框透明窗口，或带有 `overflow: hidden` / `clip-path` 的容器，交付前必须执行自动化阴影审计。

### 执行方法
1. 读取本 Skill 内置的脚本 [`scripts/clip-audit.js`](../scripts/clip-audit.js)；
2. 将该脚本的完整函数原文贴入浏览器或 DevTools 的 `evaluate_script`（或 Playwright 的 `browser_evaluate`）中执行；
3. **透明窗 / 无边框窗口**：必须传入 `{ viewport: true }`，将窗口物理视口矩形一并纳入裁切边界计算；
4. **指定检查范围**：可通过 `{ root: '.screen' }` 限定在目标组件区域；
5. **多状态全覆盖**：必须在以下四种状态下分别运行审计：
   - 默认静态渲染态；
   - 真实 `:hover` 激活态；
   - 折叠面板展开态；
   - 动效最终落点态。

### 验收门禁标准
- 返回对象的 **`cut === 0`** 为唯一硬性通过条件（`cut` 表示被裁切半截的阴影像素数）；
- 若 `cut > 0`，审计结果会详细列出：被裁元素、被哪个祖先容器裁切、被裁方向以及超出像素值，必须按 [避坑指南](desktop-pitfalls.md) 的内外分层原则进行修复，直至 `cut === 0`；
- 返回的 `hidden` 需进行人工复核，确认是否有必须露出的关键阴影被完全隐藏。

> [!WARNING]
> **审计脚本范围盲点说明**：`clip-audit.js` 默认遍历 `scope.querySelectorAll('*')` 后代元素，不会检查 scope 根容器本身的自身投影。若要检查某个卡片的投影，必须将 `root` 指定为其父级容器，严禁将卡片自身作为 `root` 来虚报通过。

## 2. 桌面窗口外壳与系统交互验收

- [ ] **窗口原生控制**：最小化、最大化、恢复与关闭按钮在 Windows / macOS 上正常响应，点击热区与原生体验一致；
- [ ] **拖拽区隔离**：窗口标题栏拖拽区域（`-webkit-app-region: drag`）与窗口内部可点击控件（`no-drag`）完全隔离，控件所在位置不可触发整窗移动；
- [ ] **透明与无边框边缘**：无边框窗口四角圆角处无黑色或白色杂色底底边，透明区域正确透视桌面背景，无点击穿透漏洞；
- [ ] **多尺寸图标适配**：在 16px、24px、32px（任务栏/托盘）及 256px+（窗口大图）下清晰可辨，轮廓平滑无直角白边。

---

## 3. 滚动与输入法交互验收

- [ ] **CJK 输入法（IME）安全发送**：中文输入法在候选词阶段敲击 Enter 键确认选词时，严禁误触发消息直接发送；选词完成后正常敲击 Enter 发送畅通；
- [ ] **自适应高度与滚动上限**：在 Composer 中连续输入 10+ 行文字或粘贴长文本时，高度平滑自适应扩展；达到 `max-height` 上限后平滑锁定并转为内部滚动；
- [ ] **弹窗滚动槽位防抖**：打开或关闭 Dialog/Modal 浮层时，背景页面无横向突跳，滚动条槽位（`scrollbar-gutter: stable`）保持稳定；
- [ ] **流式视口跟随与回溯**：模型正在高速流式吐字时，若用户向上滑动滚轮翻看历史消息，视口立即锁定且不被强行拖拽到底部；提供便捷的“回到底部”悬浮入口。

---

## 4. Agent 控制权与状态真实性验收

- [ ] **真实状态对应**：界面的运行指示、排队位次、步骤打勾必须来自实际事件，严禁用静态定时器假冒任务执行成功；
- [ ] **授权影响透明**：在请求用户授权危险操作（如删除文件、执行命令）时，必须明确标出影响范围与目标路径；
- [ ] **中断与停止有效**：点击停止按钮后，界面明确区分“已发出停止信号”与“已安全中止”，并保留已生成的阶段产物与错误原因；
- [ ] **多窗口与会话独立性**：切换或新开任务窗口时，未发送的草稿与已附加的文件上下文保持隔离与记忆，不发生串扰或丢失。

---

## 5. 最小交付证明记录

每次完成桌面 UI 改动交付时，建议记录以下要素：
1. **运行环境**：测试所用的操作系统版本、运行时（Electron / Tauri / 浏览器）；
2. **状态覆盖**：默认态、Hover 态、展开态、长内容溢出态的实际截图或录屏证据；
3. **自动化审计回执**：`clip-audit.js` 输出的 `{ ok: true, cut: 0 }` 证据；
4. **已知未覆盖边界**：若受限于当前测试环境（如仅在 Windows 验证而 macOS 待测），如实说明。
